Request a factual correction

RealSkillSet welcomes specific corrections. Include the page URL, the exact wording in question, the proposed correction and a reliable primary source. Useful evidence includes an official provider page, current syllabus, credential description, regulator page, published refund policy or documented checkout price.

What happens next

  1. The request is checked against the cited source.
  2. If a material error is confirmed, the page should be updated.
  3. Where an update changes the meaning of a guide, the modified date should also change.
  4. Disagreement with an editorial assessment does not always require a correction, but additional evidence will be reviewed.

Course-provider updates

Providers may submit changes relating to course availability, pricing, certificate options, accreditation claims, language availability, assessment or platform features. Submission does not guarantee inclusion or favorable coverage. RealSkillSet may request public documentation before changing a comparison.

Partnership and affiliate inquiries

RealSkillSet considers partnerships that are relevant to online education, professional development, career skills and language learning. A commercial offer does not guarantee editorial placement. Sponsored content, if accepted, should be clearly labeled and separate from independent recommendations.

Technical support

When reporting a broken page or display issue, include the URL, device type, browser name, approximate time and a screenshot that does not expose private information. Common issues include stale browser caching, missing GitHub Pages files, incorrect folder paths and external links that have changed.

Priority contact topics in 2026

  • Course and certificate price changes
  • AI-learning feature updates and material limitations
  • Language availability and speech-practice changes
  • Accessibility or mobile-learning barriers
  • Expired affiliate links and misleading checkout differences

Response expectations

Complex editorial requests may require verification and are not guaranteed an immediate response. Urgent security matters should be clearly identified in the subject line, but email should not be used to transmit passwords, financial details or confidential records.
